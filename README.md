# RNA sequencing data from human corneal epithelial cells cultured on dECM

This repository is maintained by Zongjin Li Lab for the RNA sequencing study of human corneal epithelial cells cultured on decellularized extracellular matrix (dECM).

## Repository status

The repository has been initialized. Data and analysis scripts have not yet been uploaded.

## Data and analysis

Sample metadata, processed expression matrices, analysis scripts, and instructions for reproducing the analyses will be added with the project data release. Raw sequencing accession numbers and publication details will be provided when available.
